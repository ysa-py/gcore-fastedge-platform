# پلتفرم مدیریت FastEdge — معرفی فارسی

این پروژه یک **پلتفرم احراز هویت و مدیریت اشتراک Edge-Native** است که کاملاً روی [Gcore FastEdge](https://gcore.com/fastedge) اجرا می‌شود — **بدون نیاز به سرور مجازی، بدون سرور اصلی و بدون بک‌اند همیشه‌روشن**. یک فایل WebAssembly واحد هم پنل مدیریت و هم API اپلیکیشن را ارائه می‌دهد.

## قابلیت‌های کلیدی

- **موتور مجوزدهی کاربران با مرز دقیق زمانی UTC**: دسترسی فقط وقتی مجاز است که `اکنون < زمان انقضا` باشد؛ در لحظه‌ی برابری دقیقاً رد می‌شود و در **هر درخواست** مجدداً بررسی می‌گردد.
- **کنسول مدیریت حرفه‌ای با ۱۳ صفحه**: داشبورد با شاخص‌های واقعی، مدیریت کاربران/اشتراک‌ها/اعتبارنامه‌ها با تأییدهای مخرب‌زدایی، کاوشگر رخدادهای امنیتی، تحلیل‌ها، پیکربندی، سلامت ذخیره‌سازی، نقش‌ها و مجوزها، درون‌ریزی/برون‌بری دو مرحله‌ای و مرجع API.
- **کنترل‌های امنیتی واقعی**: جلسات JWT با کوکی `HttpOnly; SameSite=Strict`، رمزنگاری PBKDF2، تأیید هویت دومرحله‌ای برای عملیات مخرب، محدودیت نرخ ورود، دفاع دوگانه CSRF، CSP سخت‌گیرانه، رد قطعی در خطاهای ذخیره‌سازی (fail-closed) و نمایش یک‌باره‌ی توکن‌ها.
- **خواندن پس از نوشتن**: نوشتن‌ها طی ۱–۲ ثانیه در تمام جهان تکثیر می‌شوند؛ بافر هوشمند ۱۵ ثانیه‌ای هر نمونه، انسجام پنل را تضمین می‌کند.

## وضعیت راستی‌آزمایی‌شده

همه‌ی این موارد روی این ماشین و با آرتیفکت واقعی اجرا و تأیید شده‌اند:

| بررسی | نتیجه |
|---|---|
| تست‌های واحد و یکپارچگی Rust (`cargo test`) | ✅ **۱۲۲ از ۱۲۲** |
| Lint و قالب‌بندی (`clippy` / `fmt`) | ✅ صفر هشدار |
| تست‌های فرانت‌اند (Node) | ✅ **۱۱ از ۱۱** |
| ساخت WASM (`wasm32-wasip1`) | ✅ **۷۲۶ کیلوبایت** |
| اجرای E2E روی runtime واقعی FastEdge (نسخه 0.22.0) + Redis | ✅ **۴۰ از ۴۰ مرحله** شامل تست مرز انقضا با ساعت واقعی |
| تست مرورگر واقعی (Chromium) | ✅ ورود موفق (PBKDF2 واقعی ~۰٫۶ ثانیه) و رندر هر ۱۳ صفحه |

 موارد نیازمند حساب کاربری (مانند استقرار روی `api.gcore.com` واقعی) صادقانه در `docs/TESTING.md` به‌عنوان «اجراءنشده» ثبت شده‌اند.

## شروع سریع محلی

```bash
rustup target add wasm32-wasip1
pip install redislite
scripts/build.sh
scripts/run_local.sh    # http://127.0.0.1:8080 — ورود: bootstrap-admin / bootstrap-secret-1
```

مستندات کامل انگلیسی در پوشه‌ی `docs/` و راهنمای استقرار در `docs/DEPLOYMENT.md` آماده است.
